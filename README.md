# Red-Bot-Investment

Торговый робот для **T-Invest API** (Т-Инвестиции) на **Python 3.14+**.

Репозиторий находится на стадии research: ниже — база знаний, собранная до
написания первой строки продакшн-кода. Документы — не пересказ документации
вендора, а выжимка правил, которые нужно соблюдать, чтобы робот не потерял деньги.

## Правила работы с репозиторием

См. [`AGENTS.md`](AGENTS.md) — там зафиксированы обязательные требования:
`Decimal` вместо `float`, ключ идемпотентности до сетевого вызова, разделение
стратегии и риск-менеджера, запрет реальных сделок из тестов.
